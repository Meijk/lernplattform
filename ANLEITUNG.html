🧠 Psychotherapie Lernplattform

Struktur & Update-Anleitung — Stand Mai 2026

Dateien

📄 psychiatrie_daten.js Daten
Alle Inhaltsdaten: Störungsbilder, Therapieverfahren, Gruppen, Techniken, Med. Grundlagen, AAP-Karten. Nur diese Datei für inhaltliche Updates bearbeiten. 604 KB.
🖥 psychiatrie_app.html App
App-Logik, CSS und HTML-Struktur. Lädt psychiatrie_daten.js automatisch. Beide Dateien müssen im selben Ordner liegen. Funktioniert in Firefox direkt; in Chrome über lokalen Server.
📦 psychiatrie_lernplattform.html Standalone
Alles-in-einer-Datei. Funktioniert überall ohne Server. Ideal als Backup und für Chrome lokal. Update-Aufwand höher (muss nach Änderungen neu generiert werden).

Empfohlener Workflow für Updates

  1. Öffne psychiatrie_daten.js in einem Editor
  2. Füge neue Daten hinzu (neues Störungsbild → DISORDERS-Array; neue AAP-Karten → AAP_FLASHCARDS-Array)
  3. Syntaxcheck: node --check psychiatrie_daten.js
  4. Öffne psychiatrie_app.html im Browser → Änderungen sofort sichtbar
  5. Optional: Standalone neu generieren mit dem Merge-Skript

Lernfortschritt sichern (wichtig!)

⚠️ Lernfortschritt und Favoriten werden im Browser-localStorage gespeichert. Beim Löschen von Browserdaten gehen sie verloren.

Lösung: Nutzen Sie die Export/Import-Funktion in der App (Header-Bereich). Exportieren Sie regelmäßig eine .json-Datei — diese können Sie jederzeit wieder einlesen.

const PHARMA_DB = {...}         // Medikamentendaten pro Störung
const TECHNIKEN_DB = {...}      // Technik-Karten (28 Verfahren)
const MED_TOPICS = [...]        // 12+ Med. Grundlagen-Themen

const AAP_FLASHCARDS = [...]    // 80+ AAP-Prüfungskarten

Neues Störungsbild hinzufügen

// In psychiatrie_daten.js, DISORDERS-Array, neuen Eintrag hinzufügen:
{
  id:"neue_stoerung",
  name:"Name der Störung",
  cat:"Kategorie",           // z.B. "Angststörungen"
  icd10:"F40.x",
  icd11:"6B0x",
  haupt:["Kriterium A", "Kriterium B"],
  neben:["Zusatzsymptom 1"],
  hinweis:"Klinischer Hinweis...",
  ddx:["Differentialdiagnose 1"],
  diagnostik_inst:["Instrument 1"],
  modelle:{neuro:[...], vt:[...]},
  vt_einzel:["Intervention 1"],
  fallkonzept:["Konzept 1"],
  pharmako:"Pharmakotherapie..."
}

Neue AAP-Prüfungsfragen hinzufügen

// In psychiatrie_daten.js, AAP_FLASHCARDS-Array am Ende:
{
  cat:"Kategoriename",
  qtype:"AAP Prüfungsfragen",
  tags:["aap","Themengebiet"],
  q:"Die Frage...",
  a:"Die Antwort (HTML erlaubt)..."
}
